# Resync with mattermost-plugin-starter-template Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring this webapp-only plugin's build tooling, CI, and webapp dependencies up to date with the current `mattermost-plugin-starter-template` (pinned at commit `22ef315a11a1219d604d2a6eff6968b202d6023b`), while preserving the existing GPX-preview feature behavior.

**Architecture:** This plugin has no `server/` directory — only `webapp/`. The starter template has drifted far ahead since this repo was created: Go 1.12→1.25, golangci-lint v1→v2 config format, webpack 4→5, React 16→18, the git-based `mattermost-webapp` devDependency replaced by published `@mattermost/types`/`@mattermost/client` packages, `webapp/src/manifest.ts` switched from a committed file to one generated by `make apply`, and CI moved from a hand-rolled GitHub Actions workflow (+ a legacy CircleCI config) to Mattermost's official reusable workflow (`mattermost/actions-workflows/.github/workflows/plugin-ci.yml@main`). We pull in the template's tooling/config files wholesale (it's vendored, not customized by us) and hand-edit the handful of source files that encode our actual feature (`webapp/src/index.tsx`, `webapp/src/components/gpx_preview_override/*`).

**Tech Stack:** Go 1.25 (build tooling only), Node (version pinned via `.nvmrc`), webpack 5, React 18, TypeScript, mattermost-redux 11 / `@mattermost/types` 11 / `@mattermost/client` 11, Jest 27.

**Key verified facts (don't re-derive these — they were checked against the real npm/go packages):**
- `mattermost-redux@11.1.0`, `@mattermost/types@11.1.0`, `@mattermost/client@11.1.0` are real, published packages (verified via `npm view`).
- `FileInfo` moved from `mattermost-redux/types/files` to `@mattermost/types/files` (field `extension` unchanged).
- `Theme` moved from `mattermost-redux/types/preferences` to `mattermost-redux/selectors/entities/preferences` (same module as `getTheme`); fields `centerChannelBg`, `centerChannelColor`, `buttonBg`, `buttonColor` unchanged.
- `GlobalState` moved from `mattermost-redux/types/store` to `@mattermost/types/store`.
- `registerFilePreviewComponent`'s `override` callback signature changed from `(fileInfo: FileInfo) => boolean` to `(fileInfos: FileInfo[], post: Post) => boolean`; the rendered component still receives a single `fileInfo` prop.
- `react-dom` is no longer needed as a direct dependency — it was only required by `enzyme-adapter-react-16`, which the new template drops entirely (no more Enzyme; `tests/setup.tsx` comments out the old `mattermost-webapp/tests/setup` import).
- The official reusable CI workflow's `delivery` job (the only one needing AWS secrets) is gated on `github.repository_owner == 'mattermost'`, so it's safe to adopt for this personal fork — it's simply a no-op here.
- `react-iframe@1.8.5` declares `peerDependencies: {react: ">=16.x.x"}`, so it's compatible with React 18.
